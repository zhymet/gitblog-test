# GitBlog post frontmatter guide

GitBlog posts can be configured per post using frontmatter inside the post's markdown file.
See [https://github.com/zhymet/gitblog-test/new/main/posts](example) in the `gitblog-example` repo.

Frontmatter used in this blog post:
```yaml
---
title: GitBlog Post Frontmatter Guide
brief: Example and explanation of using markdown frontmatter to customize GitBlog blog posts.
hidden: false
---
```
